# V19 — Free Hybrid AI Assistant

## Added
- Added “مساعد حسني الذكي — مجاني” in the message center.
- Local, offline-safe follow-up suggestion based on the most recent logged contact.
- Prepares a context prompt for ChatGPT Free and opens ChatGPT in a new tab.
- No API key, no paid API calls, and no claim that local rules are generated by AI.
- Prompt advises avoiding unnecessary personal data and invented claims.
- Service worker cache version bumped to v19.

## Limitations
- ChatGPT is not embedded in the app; user copies the prepared prompt into ChatGPT.
- The app does not read WhatsApp replies automatically.
- Local suggestions are rule-based.

## Deploy
Back up the existing repository, extract this ZIP, and upload the ZIP contents to the repository root, replacing the previous files. Keep any user data backup before updating. Then reopen the hosted app and refresh; if the old version persists, close and reopen the installed PWA after an internet connection.
